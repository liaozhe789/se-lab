# 实验一：软件开发过程与Git协作实战

| 项目 | 内容 |
| --- | --- |
| 学时 | 4 |
| 项目性质 | 验证性 |
| 实验地点 | 南实训409 |

## 实验目的和要求

1. 掌握 Git 基础操作，包括版本创建、提交、推送、拉取及分支管理，加深对 Git 的理解；
2. 创建个人仓库，如 GitHub 或 Gitee；
3. 熟悉基于 Issue 和 Pull-Request 的协作开发流程；
4. 体会敏捷开发与群体化开发方法在实际项目中的应用。

## 实验环境

- 安装有 Git 客户端、EduCoder 平台客户端的 PC
- 开源软件仓库（GitHub / Gitee）账号
- EduCoder 协同开发平台账号
